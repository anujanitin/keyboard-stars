Grown-ups

Connect the piano

When the piano is connected, the app hears each key your child presses and moves on by itself. Without it, kids can tap the keys on the screen.

  1. Tablet (Galaxy Tab): use a USB-C to USB-B cable (a "printer cable" with a USB-C end). Plug the square end into the USB port on the back of the Recital Play and the other end into the tablet.
  2. Windows laptop: use a normal USB-A to USB-B cable.
  3. Turn the piano on, open this page in Chrome (or Edge on Windows), then press Connect piano and allow MIDI access if asked.
  4. Press any key on the piano. The status at the top should turn green.

Edit songs

Write notes as letter + octave (middle C is C4). Add -2 for a note that lasts 2 beats, -0.5 for half a beat. Sharps are F#4. Split lyrics into syllables with hyphens (twin-kle); use _ for a note with no word.
