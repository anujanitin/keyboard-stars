# Keyboard Stars

A piano practice app for kids. Each kid has a profile and earns stars. Songs are split into short parts, and there are two ways to play: **step by step**, where the next key glows and the app waits for it, and **play along**, with falling notes.

Built for the Alesis Recital Play with letter stickers. Open the page in Chrome (or Edge) and connect the piano over USB to use MIDI input:

- Tablet: USB-C to USB-B cable
- Laptop: USB-A to USB-B cable

Kids can also tap the keys on screen.

Everything is in `index.html`. Songs can be edited in the app under **Grown-ups → Edit songs**. Players, stars and song edits are saved in each browser.
